# imagemer-legal

Privacy Policy and Terms of Service for the Imagemer Android app, served with GitHub Pages:

- https://nefeygt.github.io/imagemer-legal/privacy/
- https://nefeygt.github.io/imagemer-legal/terms/

These replace the Google Docs `/pub` links, which on phones with the Docs app opened Docs
and asked the user to pick a Google account before showing the policy.

Text was carried over unchanged from the published Docs on 2026-11-02 (privacy last updated
29 Oct 2026, terms effective 8 Sep 2026), apart from one typo: a missing `)` in Terms §8.
Edit the HTML here when the policy changes, and keep the "Last updated" line current.
